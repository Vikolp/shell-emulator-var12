## Описание

Проект реализует эмулятор оболочки с поддержкой:

- Интерактивного режима (REPL)
- Виртуальной файловой системы (VFS), загружаемой из директории
- Базовых и расширенных команд UNIX
- Стартовых скриптов с остановкой при первой ошибке

Все операции с VFS выполняются **только в памяти**.

## Этапы разработки

| Этап | Название                 | Описание                                      |
|------|--------------------------|-----------------------------------------------|
| 1    | REPL                     | Консольный интерфейс, парсер, заглушки ls/cd |
| 2    | Конфигурация             | Параметры CLI, стартовый скрипт              |
| 3    | VFS                      | Загрузка из директории, vfs-info, default    |
| 4    | Основные команды         | ls, cd, date, pwd, cal                       |
| 5    | Дополнительные команды   | cp, mkdir (только в памяти)                  |

## Требования

- Python 3.8+

## Установка и запуск

```bash
git clone <url-репозитория>
cd shell-emulator

# Интерактивный режим (VFS по умолчанию)
python3 src/emulator.py

# С указанием VFS
python3 src/emulator.py --vfs vfs/deep

# Стартовый скрипт
python3 src/emulator.py --vfs vfs/multi --script scripts/commands_stage4.txt

# Через run.sh
bash run.sh --vfs vfs/minimal
```

### Параметры командной строки

| Параметр   | Описание                          |
|------------|-----------------------------------|
| `--vfs`    | Путь к директории VFS             |
| `--script` | Путь к стартовому скрипту         |

При запуске выводится отладочная информация о параметрах.

## Команды эмулятора

### Базовые
- `ls [path]` — список файлов и директорий
- `cd [path]` — смена текущей директории
- `exit` — выход из эмулятора

### Основные (Этап 4)
- `pwd` — текущий путь
- `date` — текущая дата и время
- `cal [month] [year]` — календарь

### Дополнительные (Этап 5)
- `cp <src> <dst>` — копирование файла/директории (в памяти)
- `mkdir <path>` — создание директории (в памяти)

### Служебные
- `vfs-info` — имя VFS и SHA-256 хеш её содержимого

## Особенности реализации

1. **Парсер** — простой, разбиение по пробелам.
2. **Приглашение** — содержит имя VFS: `vfsname:/path$`.
3. **Стартовый скрипт** — останавливается при первой ошибке.
4. **VFS**:
   - Источник — обычная директория на диске.
   - Если `--vfs` не указан — создаётся default VFS в памяти.
   - Все изменения (`cp`, `mkdir`) происходят только в памяти.
5. **Обработка ошибок** — понятные сообщения (unknown command, no such file и т.д.).
