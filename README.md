## Описание

Проект реализует эмулятор оболочки с поддержкой:

- Интерактивного режима (REPL)
- Виртуальной файловой системы (VFS)
- Базовых и расширенных команд UNIX

## Установка и запуск

```bash
# Клонирование
git clone <url-репозитория>

# Запуск
./run.sh
```

### Параметры командной строки

```bash
python src/emulator.py [--vfs PATH] [--script PATH]
```

- `--vfs` — путь к директории VFS
- `--script` — путь к стартовому скрипту

## Команды эмулятора

### Базовые (Этап 1)
- `ls` — список файлов (заглушка)
- `cd` — смена директории (заглушка)
- `exit` — выход

### Основные (Этап 4)
- `ls`, `cd` — полноценная реализация
- `date` — текущая дата и время
- `pwd` — текущий путь
- `cal` — календарь

### Дополнительные (Этап 5)
- `cp` — копирование файлов/директорий
- `mkdir` — создание директорий

### Служебные
- `vfs-info` — информация о загруженной VFS (имя + SHA-256)

## Примеры использования

```bash
# Интерактивный режим
./run.sh

# С указанием VFS
./run.sh --vfs vfs/deep

# Стартовый скрипт
./run.sh --script scripts/test_stage1.sh
```
